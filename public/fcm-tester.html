🔔 Waffer · FCM Token Tester

احصل على FCM token من متصفحك لاستخدامه في Postman وتجربة OTP عبر الإشعارات

1

إعدادات Firebase Web

احصل عليها من Firebase Console → Project settings → Your apps → Web app — إذا لم يكن لديك Web App، أضف واحدة (الأيقونة </>).

من Cloud Messaging → Web configuration → Web Push certificates

2

الحصول على FCM Token

المتصفح سيطلب الإذن للإشعارات. اقبل ثم سيظهر الـ token.

3

جرب من Postman

أرسل طلب POST {{base_url}}/auth/send-otp:

{
  "phone": "+967777172034",
  "device_token": "<لصق Token هنا>",
  "platform": "web",
  "locale": "ar"
}

📱 ستصل لك رسالة إشعار في هذا المتصفح خلال ثوانٍ تحتوي على الـ OTP.
